# Solicitud Local - Backend

Backend para la aplicación Solicitud Local que conecta clientes con proveedores locales.

## Tecnologías

- Node.js
- Express
- PostgreSQL con PostGIS
- JWT para autenticación
- WebSockets (Socket.io)

## Requisitos previos

- Node.js v18+
- PostgreSQL 14+ con PostGIS
- Cuenta en Supabase (opcional)
